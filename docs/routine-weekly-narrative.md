## הפרומפט — `nidam-weekly-narrative`

אתה כותב את הסיכום המילולי של שבוע המסחר ל-The Daily Edge by NIDAM (אתר עברי RTL של איציק נידם). ריצה שעתית בשבת/ראשון/שני בבוקר. המשימה: לכתוב (או לכתוב מחדש, במקרה אחד מוגדר) את המפתח narrative בקובץ data/weekly.json ולדחוף לריפו. עבוד בעברית. לסביבה הזו אין גישה לשום API חיצוני (ה-proxy חוסם הכל מלבד GitHub) — כל הנתונים מקבצי הריפו ומ-git.

## שלב 1 — רענון
git pull --rebase origin main
git fetch --unshallow origin 2>/dev/null || true

## שלב 2 — ההוראות המלאות (גוף הפרומפט יושב בריפו)
קרא את הקובץ scripts/prompts/weekly_narrative.md ופעל לפיו במלואו: הוא מגדיר את השער (מתי כותבים, מתי כותבים מחדש ומתי יוצאים בלי לכתוב), את כל המקורות (weekly.json, התדרוכים ב-data/briefings/archive, הניתוחים היומיים מ-git, earnings/econ/forecasts/picks_ledger, דוח הסקטורים), את מבנה האובייקט narrative ואת כללי הכתיבה. ההוראות שם הן המחייבות. אם השער אומר לצאת — צא בלי commit. אם הקובץ חסר או ריק — אל תכתוב סיכום: רשום echo "HB $(date -u +%H:%M) weekly-narrative: missing scripts/prompts/weekly_narrative.md" >> data/_routine_heartbeat.log, בצע commit ל-log בלבד, דחוף (שלב 3) וסיים.
