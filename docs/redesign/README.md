## שלב 2 — קהל ושאלות (סגור, 9.10.2026)
**סקר של איציק בקרב המשתמשים:** (1) "יש מידע טוב, אולי יותר מדי"; (2) אוהבים מאוד את **הנבחרות** ורוצים אותה בבית; (3) להבליט את **היומן** בעיקר כשיש דוחות/דיווחים או אירועי מאקרו; (4) חלק אמרו שהעיצוב "קצת בעייתי".
**תואם לנתונים:** הנבחרות 4.6 צפיות ליום (הכי הרבה אחרי הבית); הבית ≈ 45% מכל הצפיות; כפילויות (מניות ב-5 מקומות, דוחות ב-5).

**עקרון:** שכבות — הבית = תשובה קצרה לכל שאלה + קישור לעומק; העומק נשאר בטאבים. הבית דינמי: ביום עם אירוע היומן עולה למעלה.

**חמש השאלות, לפי סדר:**
1. מה מצב השוק עכשיו? — המד, הטיקר, מפת החום, הכותרת
2. מה קורה היום? — היומן: מאקרו, דוחות, עונת הדוחות (מוגבר בימי אירוע)
3. באילו מניות להתמקד? — **הנבחרות** (ומאחוריה מועמדים/מומנטום)
4. מה קרה ולמה? — הניתוח היומי, התדרוך, הבזק
5. מה קורה מסביב? — סקטורים, העולם, אופציות, Insider

**דרישות קבועות:**
1. **מדידת כניסות ברצף:** כל לשונית-משנה שומרת את השם שהיא נמדדת בו היום ב-GoatCounter (`home`, `indices`, `sectors`, `momentum`, `candidates`, `trades`, `picks`, `insider`, `briefing`, `morning`, `weekcal`, `prep`, `reports`, `world`) — אותו hash ואותו path. לטאבים העליונים החדשים (השוק, היומן, מניות, חדשות) מדידה משלהם בשם חדש. לבדוק אחרי כל טאב שעולה שהספירה ממשיכה.
2. **לא נוגעים באתר החי עד אישור** של כל שלב. מוקאפים כארטיפקטים פרטיים (קנבס Design / סוג Design System).
3. **שום תוכן לא נמחק** — עובר מקום לפי מפת האתר. הצינורות (scripts/, data/) לא משתנים; העיצוב הוא index.html + app.js + style.css.
4. **בהיר + כהה, מחשב + טלפון (390), עברית RTL.** עברית בגרפיקה = שכבת HTML, לא `<text>` של SVG (WebKit). צילום-עין לפני כל push (CLAUDE.md §8).
5. **תיאום סשנים:** סשן העיצוב הוא היחיד שעורך index.html / app.js / style.css עד סוף המעבר. סשן התפעול רק בודק; תיקון דחוף — בתיאום.

**תהליך:**
