# WorldClock
שעון עולמי: צ'יפ לכל בורסה לפי שעת הפתיחה, מצב המסחר בצבע.
- `.clock > .ck` — 28px גובה; `.live` = נסחרת עכשיו (`signal-up`), `.pre` = לפני פתיחה (ענבר — מצב שוק), `.stale` = ציטוט ישן (דהוי). בלי קלאס = סגורה.
- המצב נגזר מחותמת הזמן של הציטוט, לא מלוח שעות קבוע.
- ❌ להשתמש בצבע בלבד: שם הבורסה והשעה תמיד בטקסט.
