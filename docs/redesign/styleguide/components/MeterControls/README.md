# MeterControls
פקדי ציר הזמן של המד: טווח (30/60/90) והרכיבים, בשורה אחת מעל הגרף.
- `.mt-ctrl` — `.mt-seg` (טווח, בחירה אחת: `aria-pressed`) מימין ו-`.mt-lg` (רכיבים להדלקה/כיבוי, כל אחד עם קו בצבע הסדרה שלו) משמאל.
- פעיל בטווח = `link-bg` + `link-text`, כמו צ'יפ; רכיב מודלק = מסגרת `ink-2`.
- אותו סגנון ללחצני השביל בגלגל הרוטציה ("השבוע · יום-יום", "החודש", "כל השבילים").
- הכותרת "ציר הזמן" יושבת ב-`.ph` של הפאנל — לא בתוך הפקדים.
