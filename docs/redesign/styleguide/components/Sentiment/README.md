# Sentiment
שורת סנטימנט: תווית קצרה עם נקודת כיוון, ומשפט אחד.
- `.sent` — עמודת תווית 88px (72 בטלפון) ומשפט; שורות מופרדות בקו-שיער (`.pb.bd-sents`).
- הנקודה: `.dot.up` / `.dot.down` לכיוון, `.dot.warn` (ענבר) **רק** לאזהרת מצב שוק (למשל אזהרת SPX), בלי נקודה = ניטרלי.
- משמשת גם ל"הכסף הגדול" ול"הצעות לטרייד" — שם התווית היא הטיקר (`.tk`, מונו).
- מה הצרכן מספק: 2–5 שורות, כל אחת עובדה אחת. ❌ שתי עובדות בשורה; צבע בלי מילה שמסבירה אותו.
