# CompactTable
טבלה קומפקטית (13px) לכל טבלה שאינה טבלת הנבחרות.
- `.tbl > table.bd-tbl` — הגלילה האופקית על `.tbl`, לא על הדף. כותרות 12px ב-`ink-muted`, שורות מופרדות בקו-שיער, `nowrap`.
- `tr.sec` = שורת-ביניים (קבוצה/יום) על `surface-panel-2`.
- הטיקר `a.tv` במונו ובדיו; ריחוף כחול — פותח את חלון הניתוח הטכני.
- כל תא מספרי `dir="ltr"` (אחרת "6.6-"); סיכון מעל 5% ב-`signal-down`, יעד ב-`signal-up`.
- `<caption class="sr-only">` ו-`scope="col"` לנגישות.
