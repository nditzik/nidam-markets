# BetRow
שורת הימור: שאלה, פס הסתברות, אחוז, שינוי יומי בנקודות.
- `.bet` — ארבע עמודות: התווית (קישור למקור) + ההימור המוביל מתחת · פס על `graphic-track` (LTR, מילוי `ink-2` — הסתברות היא לא כיוון) · האחוז במונו · השינוי היומי בנקודות בצבע + סימן.
- בטלפון: רק התווית והאחוז.
- מקורות: Polymarket + Kalshi. ❌ לצבוע את הפס לפי "טוב/רע".
