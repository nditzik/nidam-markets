# KeyValue
שורת מפתח-ערך עם קו-שיער עליון, בתחתית פאנל.
- `.kv` — המפתח ב-`ink-muted` (לא נשבר), הערך ב-`ink-2`; קו-שיער מעל מפריד מגוף הפאנל.
- לסיכום אחד בשורה: "לאן זרם הכסף", "העונה עד כה", "המקור".
- מספרים ב-`.n`; בכיוון קריאה עברי ("35% ← 25%" = עכשיו ← לפני).
- ❌ יותר משתי שורות `.kv` רצופות — אז זה Table.
