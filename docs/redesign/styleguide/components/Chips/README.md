# Chips
צ'יפים: בחירה בתוך פאנל — קטגוריה, מהדורה, תאריך בארכיון, טיקר.
- `.bd-chips > .tag` — 28px גובה, `.on` = הנבחר (`link-bg` + `link-text`, כמו לשונית-משנה פעילה). כפתור (`button`) כשהוא מחליף תוכן, קישור כשהוא יוצא.
- ארכיון ארוך (`.rep-arch`): **שורה אחת נגללת**, לא שלוש שורות של תאריכים.
- ספירה בתוך הצ'יפ ב-`<b class="n">`. ❌ אמוג'י בצ'יפ; גלולה שחורה כפעיל.
