# Explainer
"איך זה עובד": ההסבר של לשונית, מקופל כברירת מחדל, בפאנל האחרון.
- `details.bd-exp > summary` — "▸ איך זה עובד" (13px/600, `ink-2`); פתוח: "▾" והטקסט בריפוד `space-4`.
- כל לשונית שיש לה הסבר שמה אותו כאן — לא כקופסת מבוא מעל התוכן (התוכן קודם; מי שצריך הסבר פותח).
- גם החלקים המקופלים בחלון הניתוח הטכני ("אינדיקטורים וממוצעים"…) באותו סגנון.
- ❌ ההסתייגות המשפטית בתוך ההסבר בלבד — היא בתחתית האתר.
