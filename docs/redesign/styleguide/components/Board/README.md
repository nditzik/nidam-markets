# Board
הרשת של כל טאב: 12 עמודות של פאנלים, `gap: space-3`.
- כל טאב הוא `<div class="board">` ובתוכו `<section class="pan">` עם `grid-column: span N` (inline, דרך `bdSpan(n)` ב-app.js).
- פאנל ריק (`.pan:empty`) נעלם — פאנל שהנתונים שלו לא הגיעו לא משאיר חור.
- מתחת ל-1100px כל פאנל `span 12`; בטלפון עמודה אחת באותו סדר.
- מה הצרכן מספק: סדר הפאנלים לפי השאלה שהטאב עונה עליה, ורוחב לכל אחד (12 / 8+4 / 6+6 / 4+4+4).
- ✅ פאנל ראשי ברוחב מלא עם אריחים, אחריו התוכן. ❌ רשת בתוך פאנל; רוחב שלא מסתכם ב-12 בשורה.
