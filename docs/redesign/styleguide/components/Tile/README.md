# Tile
אריח סטטיסטי: תווית קטנה מעל, ערך מונו 20px, שורת משנה.
- `.tiles > .tile` — ארבעה בשורה; `.t2` / `.t3` לשתיים/שלוש. בטלפון שניים בשורה, הערך 18px.
- הערך (`.v`) במונו, LTR; נצבע `.up` / `.down` רק כשהוא שינוי. רמה (מחיר, ספירה) נשארת `ink-1`.
- שונה מ-KPI: KPI הוא פס אחד עם קווי-שיער בין התאים (מצב השוק בבית); Tile הוא אריח נפרד עם מסגרת, לפאנל-הראשי של לשונית.
- מה הצרכן מספק: 2–4 מספרים שעונים על "כמה ומה המצב" לפני הטבלה. ✅ "מועמדים 65 · מוצגים 60". ❌ טקסט ארוך בתוך הערך.
