# IndexCard
כרטיס מדד בטאב העולם: שם + שינוי, מחיר/שבוע/השנה, ספארקליין, מצב.
- `.wgrid > .wc` — שלושה בשורה (`.g2`/`.g1` לשניים/אחד).
- שורה עליונה: שם המדד ושינוי היום (צבע + סימן); שורה שנייה (`.m`): מחיר, 5 ימים, מתחילת השנה; ספארקליין LTR; `.wc-s` = מצב המסחר ("סגור · 09/10").
- כשהבורסה סגורה השינוי הוא של יום המסחר האחרון (מהנרות היומיים) — לא 0.00%.
