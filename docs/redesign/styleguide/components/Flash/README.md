# Flash
המבזק: תנועה חדה (0.5%+ ב-30 דקות) ומה התפרסם באותן דקות.
- `.flash` — האחוז הגדול (28px מונו, צבע + סימן) ותחתיו המכשיר והשעה; בצד (`.fx`) הראיות: נתון מאקרו, בזקים, כותרות.
- הכותרת אומרת "מציג מה התפרסם באותן דקות, לא סיבתיות" — המבזק לא טוען שהידיעה גרמה לתנועה.
- TTL שלוש שעות: אחריהן הכותרת "המבזק האחרון" במקום "תנועה חדה עכשיו".
