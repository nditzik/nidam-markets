# מגזין סוף השבוע (np207, 15.11.2026)

כתבה אחת בשבוע, על חברה או על נושא מאקרו. מוצגת בבית (`#home-mag`) ונפתחת לדף מלא בטאב חדשות, לשונית "מגזין סוף השבוע" (`#panel-magazine`, hash `#magazine`). מוקאפ שאושר: https://claude.ai/artifact/82LJgEbAte3wReLGDxbdEj

**הכתבות הן מידע בלבד, לא המלצה.** זה התנאי של איציק לכל הפיצ'ר, והוא גובר על כל שיקול עריכה אחר.

## התהליך השבועי

1. **במהלך השבוע** — הבוטים של איציק אוספים חומר ושולחים קובץ (כמו `nvidia_article_update_for_claude_*.md` של גרוק). אין איסוף מהרשת בסשן.
2. **שישי בבוקר** — בוחרים נושא אחד.
3. **שישי–שבת** — כותבים את קובץ הגיליון בסשן, מריצים `python3 scripts/lint_advice.py` (חייב 0 ממצאים), בודקים בצילום מחשב + טלפון, ודוחפים. הכתבה עולה בשבת בבוקר.
4. **עדכון באמצע סוף השבוע** — קובץ נוסף מהבוט → מעדכנים את אותו קובץ גיליון, `updatedLabel` ו-`_meta.updatedAt`. אין צורך בהקפצת np (שינוי נתונים בלבד).

בבית: בשבת ובראשון הפאנל ראשון בדף (class `mg-first`, לפי שעון ישראל); משני עד שישי מתחת לכותרת השוק ולמד, עד שהגיליון הבא מחליף אותו.

## הקבצים

- `data/magazine/index.json` — `{current, issues[]}`. `current` = מזהה הגיליון שמוצג בבית. `issues` מהחדש לישן: `{id, no, date, kindLabel, sym, title}` (לרשימת "גיליונות קודמים").
- `data/magazine/<id>.json` — הגיליון. מזהה: `YYYY-MM-DD-<נושא>` (תאריך השבת).

### מבנה גיליון

| שדה | תוכן |
|---|---|
| `id`, `no`, `date` | מזהה, מספר גיליון, תאריך הפרסום (ISO) |
| `updatedLabel` | "15.11 בבוקר" — מוצג כ"עודכן …" |
| `kindLabel`, `sym` | "חברה" / "מאקרו"; טיקר (רשות) — מוצגים כתג הראשון |
| `tags[]` | תגים נוספים בכותרת, למשל "חלק מהטענות לא הוכחו". התג "מידע בלבד, לא המלצה" קבוע בקוד |
| `title`, `dek` | כותרת + שתי שורות |
| `collectedBy` | "איסוף: גרוק, ממקורות פומביים · עריכה: The Daily Edge" |
| `numbers[4]` | `{v, label, sub, dir}` — `dir` "up"/"down" צובע; `v` עם סימן ומינוס אמיתי (−) |
| `live[]` | `{sym, label}` — מחיר חי מ-Yahoo דרך ה-Worker, בדף הכתבה |
| `brief[5]` | "בקצרה" — חמש שורות |
| `sections[]` | `{h, paras[]}` — גוף הכתבה, פרק לכל כותרת |
| `known[3]` | `{head, mark: ok/part/no, items[{t, src}]}` — "מה ידוע, מה דווח ומה מוכחש" |
| `table` | `{title, head, rows[[יום, סגירה, שינוי, מה קרה]], chartSkip[], mark{d,label}, note}` — הגרף נבנה מהשורות; `chartSkip` = ימים שלא בגרף |
| `timeline[]` | `{d, t, txt, src, url, key, top}` — `top` = מוצג ב"עיקרי האירועים"; `key` = מודגש |
| `thirdParty` | `{title, lead, items[{name, text, sub}], note}` — מה פרסמו אחרים (יעדי אנליסטים וכד') |
| `questions[]` | שאלות פתוחות (4 ראשונות גלויות) |
| `next[]` | `{d, t, txt}` — "מה הלאה". `d` בצורת "17.11" או "16–20.11"; מועד שעבר מוצג דהוי ולא מופיע בבית |
| `sources[]` | `{name, url}` — בלי `url` = טקסט בלי קישור |
| `corrections[]` | `{at, text}` — מוצג בתחתית כ"תיקון D: …" |

פרק בלי תוכן פשוט לא מוצג, כך שכתבת מאקרו יכולה לוותר על `table`/`thirdParty`/`known`.

## כללי עריכה (מחייבים)

1. **אין בכתבה:** מה לעשות עם נייר ערך, יעד או הערכת שווי של האתר, כניסה/יציאה/סטופ, "כדאי", "הזדמנות". הכללים המלאים: `scripts/prompts/_language.md`.
2. **כל טענה מיוחסת למקור.** טענה שלא אושרה רשמית נכתבת "לפי X" ומופיעה בעמודה "דווח, לא אושר רשמית".
3. **"אושר רשמית"** = רק מה שמופיע בהודעת החברה, בדיווח לרשות או בהודעה של גוף רשמי. דיווח עיתונאי, גם אמין, אינו אישור רשמי.
4. **אנשים פרטיים שנקשרו בטענות אינם מוזכרים בשמם**, ואין ציטוטים אישיים עליהם. נושאי משרה ואנשי ציבור — בשמם.
5. **יעדים ודירוגים של בתי השקעות** רק בבלוק `thirdParty`, עם שם המפרסם, ועם ההערה "נתוני צד שלישי כפי שפורסמו, לא עמדה של האתר".
6. **בלי עובדות שלא בקובץ של הבוט.** "בקצרה" ו"מה ידוע" הם תמצית של גוף הכתבה, לא מקום למידע חדש.
7. **בלי משפטים שמתיישנים** ("אתמול", "מחר"): תאריכים מפורשים, שעות בשעון ישראל.
8. **טעות** — מתקנים ומוסיפים שורה ל-`corrections`. לא משכתבים בשקט.
9. מספר חתום בתוך משפט: מינוס אמיתי (−). צירוף כמו "8-K" מבודד אוטומטית בתצוגה (`magTx`).
