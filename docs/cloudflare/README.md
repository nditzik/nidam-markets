# שכבה 2 של "נתח מניה" — המתווך ב-Cloudflare

**למה צריך את זה:** לניתוח הטכני המלא (תמיכות, התנגדויות, מכונת הפריצה, הגרף) צריך שנתיים של נרות יומיים.
למניות שהאתר עוקב אחריהן הנרות כבר שמורים ב-`data/bars`. למניה אחרת הדפדפן לא יכול להביא אותם בעצמו
(Yahoo לא מאפשר לאתרים אחרים לקרוא ממנו), והשרתים של GitHub חסומים אצל Yahoo. לכן מתווך קטן אצל Cloudflare:
הדפדפן מבקש ממנו, הוא מבקש מ-Yahoo ומחזיר. חינם (עד 100,000 בקשות ביום), בלי מפתחות ובלי מידע אישי.

## מה עושים (פעם אחת, ~5 דקות)

1. נכנסים ל-https://dash.cloudflare.com/sign-up ופותחים חשבון חינמי (מייל + סיסמה, לאשר את המייל).
2. בתפריט מימין/משמאל: **Compute (Workers)** → **Workers & Pages** → כפתור **Create** → **Create Worker**
   (אם מופיעות תבניות — לבחור **Hello World**).
3. שם ל-Worker: `nidam-bars` → **Deploy**.
4. אחרי הפריסה: **Edit code**. מוחקים את כל מה שבחלון, ומדביקים את כל התוכן של הקובץ
   `docs/cloudflare/bars-worker.js` מהריפו.
5. כפתור **Deploy** (למעלה מימין).
6. מעתיקים את הכתובת של ה-Worker — נראית כמו `https://nidam-bars.<השם-שלך>.workers.dev`.
7. שולחים את הכתובת לקלוד. זהו.

**בדיקה עצמית (לא חובה):** לפתוח בדפדפן `https://nidam-bars.<השם-שלך>.workers.dev/bars?s=AAPL` —
אמור להופיע טקסט ארוך שמתחיל ב-`{"symbol":"AAPL","bars":[[...`.

## מה קלוד עושה עם הכתובת

שורה אחת ב-`assets/app.js`: `window.__barsProxy = "<הכתובת>";` + הקפצת גרסה. מאותו רגע, טיקר שלא במעקב
באתר מקבל את הניתוח הטכני המלא (אותו מנוע כמו בנבחרות) + יסודות החברה מהסורק של TradingView.
אם המתווך לא עונה (תקלה, Yahoo חוסם) — האתר חוזר לבד לניתוח המקוצר של שכבה 1. שום דבר לא נשבר.

## פרטים טכניים

- `GET /bars?s=SYM` → `{symbol, bars:[[date,o,h,l,c,v],…], source:"yahoo", exchange, currency}` — שנתיים, יומי.
- סמל: אותיות לטיניות, עד 7 תווים (נקודה → מקף, BRK.B → BRK-B). אחר → 400.
- CORS רק ל-`https://nditzik.github.io` (+ localhost:8765 לבדיקות) — אתרים אחרים לא יכולים להשתמש בו מדפדפן.
- מטמון שעה בקצה של Cloudflare: הרבה מבקרים על אותה מניה = בקשה אחת ל-Yahoo בשעה.
- באתר (`assets/ta_ui.js`, `proxyBars`): המתנה עד 8 שניות, לפחות 60 נרות, הנר של היום נזרק בזמן המסחר
  (במקומו הנר החי מהסורק, כמו במניות במעקב), מטמון 30 דקות בדפדפן.
- לעדכן את הקוד: לחזור ל-Edit code ב-Cloudflare, להדביק את הגרסה החדשה, Deploy. הכתובת לא משתנה.
