# "הצעות לטרייד" — המילים לדוח ארבעת העמודים (24.10.2026)

רץ כחלק מהרוטינה היומית (סעיף 7 ב-`daily_analysis.md`), **אחרי** סעיפים 5–6. אם משהו כאן נכשל — מדלגים, הניתוח היומי לא נפגע.

**הרקע:** בוט של איציק מוריד שלישי–שבת ב-06:00 שעון ישראל את שלושת סורקי "ארבעת העמודים" של Barchart (High Momentum / Breakout Candidates / Phoenix Rising) ושולח במייל. ה-Action של האתר שומר אותם ל-`data/fourpillars/<יום המסחר>/` ו-`scripts/build_fourpillars.py` עושה את **המספרים**: אימות הקריטריונים, ציון 0–100, דגלים, רמות (טריגר = שיא 52 שבועות, ממוצע 100 = קו היציאה), מצב השוק. **אתה כותב את המילים** — הערה לכל מניה, המובילות והשורה התחתונה — והסקריפט מרכיב מהן את הדוח `data/trades/trades-<יום>.html` (הטאב "הצעות לטרייד").

## 1. האם יש מה לכתוב

1. מצא את התיקייה החדשה ביותר ב-`data/fourpillars/` (שם = `YYYY-MM-DD`, יום המסחר) שיש בה `report.json`.
2. צריך לכתוב כש**אין** בה `notes.json`, או שה-`tradeDay` שבו שונה משם התיקייה.
3. אין כזו — סיים את הסעיף בלי לגעת בקבצים. כותבים ליום אחד בלבד (החדש ביותר).

## 2. חומר הגלם (הכל מקבצי הריפו — אין רשת)

1. **`data/fourpillars/<D>/report.json`** — המקור העיקרי. `market` (SPY מול ממוצע 50/20, `meter`+`gate`, `vix`+`vixState`), ולכל קטגוריה ב-`cats` רשימת מניות עם: `sym, name, industry, score, status` (ok/warn/fail), `checks` (הקריטריונים ✓/◐/✗), `flags` (דגלים: מד חום חם, דוח קרוב, בנבחרות…), `last, d5, alpha, opRaw, rsi, nh` (שיאים חדשים בחודש), `offHi` (מרחק מהשיא, שלילי), `m1, m3, y1` (תשואות), `ma100`, `levels` (`trigger` = השיא, `triggerHe`, `stopHe`).
2. **הניתוח היומי שכתבת הרגע** (`data/claude_analysis.json`) — מצב השוק, הסקטורים שבולטים, מה מסוכן השבוע.
3. **`data/weekly.json.narrative.sectors` / `data/sector_rs.json`** — לאן זרם הכסף; מניה בסקטור שהכסף נכנס אליו = נקודת זכות, שיוצא ממנו = להזכיר.
4. **`data/earnings.json`** (`window`/`week`) — מניה שמדווחת ב-7 הימים הקרובים: לציין "דוח ב-D.M — לא לפתוח לפני".
5. **`data/picks.json`** — מניה שגם בנבחרות של היום: לציין (הדגל כבר שם).
6. אל תמציא מספר שאין בקבצים. בלי רשת — הכל מהריפו.

## 3. מה לכתוב — `data/fourpillars/<D>/notes.json`

```json
{
 "tradeDay": "<D>",
 "writtenAt": "<ISO UTC, למשל 2026-10-28T04:12:00Z>",
 "writtenBy": "daily-analysis",
 "headline": "<כותרת אחת, עד ~110 תווים: מה הסריקות אומרות היום מול מצב השוק>",
 "summary": "<2–4 משפטים: מצב השוק (ממוצע 50, המד, VIX) ומה זה אומר לכל קטגוריה — בשוק מתחת לממוצע 50 מעדיפים רגועות וקרובות לשיא; מי הקבוצה המעניינת היום>",
 "notes": {"<SYM>": "<עד 2 משפטים לכל מניה: למה היא מעניינת/לא, מה הטריגר (מספר מ-levels), ומה הסיכון>"},
 "top": [{"sym": "<SYM>", "text": "<2–3 משפטים: למה היא מובילה, הטריגר, היציאה, גודל הפוזיציה>"}],
 "redFlags": ["<עד 3 משפטים על השבוע כולו: אירועי מאקרו/דוחות שמשפיעים על כולן; מה חסר בנתונים>"],
 "bottom": "<פסקה אחת, מותר <b>: רשימת המעקב עם הטריגרים · מי ממתינה · מי בחוץ ולמה · כלל הכניסה>"
}
```

- `notes` — **לכל מניה** ב-`cats` (גם `fail`). `top` — 3–5 מניות, הכשירות (`status` ≠ fail) עם הציון/הפרופיל הטוב ביותר **למצב השוק**: בשוק מתחת לממוצע 50 להעדיף מד חום 50–65 וקרבה לשיא על פני זינוקים חדים.
- **לעולם לא "לקנות עכשיו"** — תמיד רשימת מעקב + טריגר (סגירה מעל השיא / כיבוש ממוצע 100 בנפח) + יציאה (סגירה מתחת לממוצע 100). מד חום (RSI) מעל 70 = "חמה — לחכות לנשימה". עוף חול מתחת לממוצע 100 = "עוד לא".
- **שפה:** עברית פשוטה, בלי ז'רגון (לא "Weighted Alpha" אלא "עוצמה", לא "RSI" אלא "מד חום", לא "Opinion" אלא "חוות דעת Barchart"); מספרים כפי שהם בקובץ; טיקרים באנגלית. מד ייחוס: "S&P 500".
- **אסור:** להבטיח תשואה, לכתוב "תקנה"/"תמכור", להמציא דוח או חדשה שאין בקבצים.

## 4. בנייה ושמירה

1. שמור את `data/fourpillars/<D>/notes.json` (UTF-8, JSON תקין — בדוק עם `python3 -c "import json;json.load(open('data/fourpillars/<D>/notes.json'))"`).
2. הרץ `python3 scripts/build_fourpillars.py` (בונה מחדש את הדוח עם המילים; בלי ארגומנטים = כל יום שה-notes שלו חדש).
3. הוסף לקומיט של הניתוח היומי: `git add data/fourpillars data/trades data/trades.json`.
4. רשום ב-heartbeat: `echo "HB $(date -u +%H:%M) fourpillars notes written (day=<D>)" >> data/_routine_heartbeat.log`.
